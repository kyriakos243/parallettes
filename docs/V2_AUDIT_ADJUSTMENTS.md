# Parallette25 V2 audit adjustment

The authoritative specification proposed 163 unique exercises and explicitly allowed a documented, audit-approved adjustment when the final count remained quality-driven.

The production database contains **195 unique exercises**: 40 retained audited movements and 155 V2 additions. The expanded audit preserves stable exercise IDs already used by saved plans and adds 25 research-led movements for active lower-body mobility, posterior-chain core balance, parallette grip-pressure control, L-sit development, scapular pushing, static flexibility swaps and no-rope rhythm work.

The adjustment was accepted only after these checks:

- every movement has distinct programming metadata and a defined role;
- Core/Abs remains the largest family;
- all warm-up movements are dynamic and all cooldown movements are static;
- the rope pool contains three warm-up/mobility options and seven conditioning options;
- all 195 movements use one owned multi-keyframe/static Parallette25 rig;
- all canonical 25- and 30-minute plans, role-aware swaps, readiness regressions and Custom Session combinations validate.

The count is not a volume target. Any future addition must replace a redundant movement or pass the same transfer, safety, media and programming audit.

The 25-movement research expansion is explicitly regression-tested so none of its exercise IDs, motion guides, readiness fallbacks or structured targets can disappear silently.

## Account security adjustment

The original V2 specification described username-only profiles. Later product review demonstrated that this exposed one person's training data to other visitors and allowed duplicate names across devices. The released implementation therefore supersedes that part of the specification with case-insensitive unique usernames, password authentication, recovery codes, private account endpoints and device-local sessions. Existing local profiles remain usable offline and can be secured once without losing progress.
